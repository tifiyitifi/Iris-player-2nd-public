# IRIS —— 基于上游 IRIS 项目的二次开发版

[English](./README.md) | 中文

## 关于本项目（二次开发说明）

本项目基于开源项目 IRIS 二次开发而来：

https://github.com/nini22P/Iris

原版提供轻量级的本地 / WebDAV / FTP 视频播放能力；本 fork 在此基础上深耕
播放组织与桌面体验，新增了场景播放、虚拟媒体、Tag 播放、副音同步播放、
MediaDb 媒体库、PotPlayer 桌面键位等大量功能（见「二开新增功能」）。与原版
的主要差异见「与原版的区别」对照表。

本项目继承 MPL-2.0 许可证，`LICENSE` 文件保持不变；依赖与源码版权声明
亦保持原样。

原版特性（继承自上游）：
- [X] 基于 [Media Kit](https://github.com/media-kit/media-kit) | [FVP](https://github.com/wang-bin/fvp)，可播放多种视频格式

- [X] 可切换字幕和音轨
- [X] 播放队列支持随机和重复
- [X] 完善的手势支持
- [X] 自定义桌面入口：自定义图标与名字，可绑定场景 + 标签独立播放

- [X] 元数据驱动的设置引擎（数据库持久化，可导入导出）
- [X] 场景播放：命名可复用的播放计划（覆盖 / 追加 / 批量生成）
- [X] 虚拟媒体规则与合并播放
- [X] Tag 虚拟合集与数字命令语法

- [X] PotPlayer 桌面键位方案、可自定义键位、A-B 区段循环
- [X] 桌面右键菜单、侧边播放列表、键盘 OSD

## 二开新增功能

以下功能均为本 fork 新增，原版 IRIS 没有。每条注明入口路径。

### 1. 元数据设置引擎

设置以声明式定义驱动同一套渲染、存储与可见性逻辑，值持久化到数据库，
首次开启时从旧配置一次性导入。入口：设置弹窗的播放 / 通用 / 关于 / 依赖
4 个标签页；部分实验性行仅在元数据系统开启时可见。

### 2. 场景播放

把「从哪播、怎么排、怎么循环」存成命名可复用的播放计划，与运行时状态分离。
入口：存储弹窗 → **场景**。
- 覆盖播放（Play Override）：替换当前播放工作区并开始播放
- 追加播放（Play Append）：合并内容而不清空当前范围
- 预览队列：只读解析结果，不落库
- 创建场景：单个创建或自动生成（批量，名称模板 + 数量 + 起始序号）
- 源管理：目录源、条目源、目录/条目排除规则
- 扫描更新源数据：刷新场景的媒体解析结果

### 3. 虚拟媒体

按规则把多段媒体合并为一个虚拟条目连续播放。入口：设置 → 播放 →
虚拟媒体。规则变更会即时反映到场景列表；与 Tag 视图可联动。

### 4. Tag 虚拟合集

不按目录、按标签组织虚拟合集，每个标签有自己的播放书签，切换标签即换
播放列表。入口：播放器更多菜单 / 设置 → 通用 → Tag 播放。
- 命令输入条（桌面）：`+n` 加入、`-n` 移除、`*n` 切到标签视图，多序号用点连接（如 `+1.2.5`）
- 记录保留策略（永久保留 / 按时长自动清理）与回切窗口
- Pin 套装：保存当前标签钉选顺序为命名预设
- 预置保留标签：收藏（永久保留 + 回跳）、副音备选（副音默认候选源）

### 5. 副音同步播放

与主视频同步播放第二条音轨/视频（如另一配音、解说）。入口：控制栏
副音菜单 / 设置 → 播放 → 副音。
- A-P-B 时间映射：把前台窗口对齐到后台文件的对应区间，逐视频保存
- 候选源规则：按标签成员、文件夹、单文件或交集有序匹配
- 控制交接：控制栏/键盘/手势可指向主视频或副音，蓝色边框指示当前目标
- 对齐调校：吸附、拉伸比告警（0.5×–2.0× 之外提示）、快用完提醒

### 6. MediaDb 媒体库

对扫描过的存储建立可持久化的媒体索引。入口：**MediaDb** 标签页；
扫描选项：设置 → 通用 → 媒体库扫描。
- 系统库按存储自动维护，移除存储的节点归入 Detached 库，不静默删除
- 三种浏览：路径树（含面包屑）、全部媒体、全部目录；名称/大小/时长/分辨率/修改时间排序
- 递归扫描：进度浮层，可暂停/继续/中断续扫，支持深度探测时长与分辨率
- 独立搜索页：分页搜索、范围（全部/当前目录递归/直属）、高亮、播单个/播文件夹/追加/覆盖
- 批量选择：多选后加入队列、覆盖队列、播文件夹、设为源、从库删除（只删索引，不删磁盘文件）

### 7. 自定义桌面入口

为 IRIS 创建自定义图标与名字的桌面入口（Android 桌面快捷方式），每个入口
可拥有独立播放工作区并绑定场景 + 标签。入口：设置 → 通用 →
Custom desktop entries。Android 8.0+，部分第三方桌面不支持。

### 8. 手机手势与单手操作

入口：设置 → 播放 → 手势布局 / 单手。
- 手势分区编辑：按意图（单击/双击/长按/滑动等）逐区域指派动作，支持左右手布局
- 手势引导浮层：播放器更多菜单可打开当前布局的可视化指南
- 单手环形进度盘：横屏侧栏的双圈拨盘（整片定位 + 块内精调），拇指可达的角落快捷键
- 速度手势：单轴（仅横滑 0.1 微调）/ 双轴（横滑 0.1 + 竖滑 1.0）

### 9. 桌面键盘

两套键位方案，在 **设置 → 播放 → Keyboard shortcut scheme** 中切换：
- **PotPlayer (Windows)**：对齐 PotPlayer 官方默认键位（详见键位表）
- **IRIS classic**：原有键位，元数据系统关闭时始终生效
- 可自定义键位：任意动作可绑多个组合，冲突检测；仅桌面
- `；` 前缀序列：`; F` 存储、`; H` 历史、`; P` 侧边队列、`；R` 循环、`; X` 随机
- A-B 区段循环：`[` 设 A、']' 设 B 并启动、`B` 快速布防/重置
- `Shift + Delete`：把播放中文件移入回收站（仅 Windows，可确认）

### 10. 桌面界面

- 右键菜单：PotPlayer 风格的播放器上下文菜单（打开/播放/视频/音频/字幕/窗口/面板）
- 侧边播放列表：桌面右侧停靠队列，宽度可拖，支持全屏悬停唤出（右侧边缘热区）
- 桌面控制栏布局：经典单行 / PotPlayer 风格三行
- 键盘 OSD：桌面按键的瞬时屏显反馈（音量/进度/速度/轨道切换等），9 宫位置可配；入口：设置 → 通用 → 键盘 OSD

### 11. WebDAV 自动发现

存储条目的主机可写成通配符（如 `192.168.1.*`），连接时自动找到实际设备：
缓存命中 → SSDP 发现 → 子网扫描，密码错误会明确提示而非静默重扫。入口：
添加/编辑 WebDAV 存储对话框；查找模式：设置 → 通用 → WebDAV 主机查找。

### 12. 播放工具与数据迁移

- 截图：保存当前帧为 PNG（需 mediaKit 后端）；手机为可拖动浮动面板，也有更多菜单直达项
- 逐帧：点按单步（先暂停），长按连续步进；入口：更多菜单 → 帧工具
- 打开方式（仅 Android）：把本地文件交给其他应用打开
- 截图目录：设置 → 播放 → 截图保存目录（手机/桌面分开）
- 设置导入导出：设置 → 通用 → 数据；按模块（设置/历史/收藏/场景/Tag/虚拟媒体/网络存储）选择，含网络存储时强制加密口令
- 密码导入导出日志：审计每一次触及密码的导入导出（时间/操作/加密情况/结果），仅清空、不单条删除

## Android 安装包

Android 的原生库与 CPU 架构绑定，因此 IRIS 同时发布 3 个分架构 APK 和 1 个通用 APK：

- `IRIS-android-arm64-v8a-*.apk` —— 64 位 ARM，**绝大多数手机**（约 2016 年后）都是它。
- `IRIS-android-armeabi-v7a-*.apk` —— 32 位 ARM，较老或低端设备。
- `IRIS-android-x86_64-*.apk` —— x86_64 模拟器、极少数 Intel 设备。
- `IRIS-android-universal-*.apk` —— 包含以上全部架构，任何受支持的设备都能安装。

分架构包只带本架构的原生库，体积小得多；
通用包三种架构全带，安装后体积约为其 2～3 倍。

**不知道手机架构就选 universal 包**，代价是安装体积增大。
若想省体积，可先试`arm64-v8a`（绝大多数手机属于此架构）；
只有当系统以"架构不匹配"为由拒绝安装时，再尝试其它或选 universal 包。

### 在几种包之间切换

4 个 APK 共用同一个包名和签名，安装时 Android 会比较 versionCode。分架构包的
versionCode 会被改写成 `架构 × 1000 + base`（arm64-v8a = base + 2000），universal
包保持纯 base。因此：

- universal → 任意分架构包：**升级**，直接覆盖安装，数据全部保留。
- 任意分架构包 → universal：**降级**，系统会拒绝安装
  （`INSTALL_FAILED_VERSION_DOWNGRADE`），除非先卸载。
- 分架构包之间：`x86_64`（base + 4000）> `arm64-v8a`（base + 2000）>
  `armeabi-v7a`（base + 1000），往小的是降级。

被降级拦住又不想丢数据，二选一：用 `adb install -r -d <apk>` 原地降级（要求签名
一致，官方包满足）；或卸载 → 重装 → 用设置导出/导入还原。开发者同理：装过分架构包
后再用 Android Studio 覆盖安装会被判定为降级，因此开发期手动安装请用 universal 包，
且任何 `adb install` 之前先跑 `scripts/check-apk-install.ps1`。

**设置导出/导入**（设置 → 通用 → 数据）覆盖：设置、历史、收藏、场景、Tag 播放、
虚拟媒体、网络存储（含密码，用你自设的口令加密）。**不**覆盖：媒体库索引、扫描状态、
本地存储路径、播放队列、当前播放位置——重装后需重新添加本地存储并重新扫描媒体库。

## 便携版(Windows)

Windows 便携版压缩包（从 **Release** 页面下载）为免安装便携版，解压即可使用，并请注意以下几点：

- **数据位置**:所有数据(媒体库数据库、场景、Tag 播放、播放历史、界面设置等)保存在 exe 同目录的 `userdata\` 文件夹中(`db\` 为数据库,`settings\` 为界面设置)。移动位置或换机时,把整个目录一起拷贝即可。
- **应用内更新**: 在 **设置 → 关于 → 检查更新** 中点击「下载并更新」，应用会自动下载新包并调用同一个更新脚本：IRIS 退出 → 弹出更新窗口执行覆盖 → 自动重新打开新版本（若更新脚本根本无法启动，IRIS 会保持打开并说明原因）。脚本会留下日志，并把下载包保留在 `userdata\updates\`；下次启动会汇报本次更新是否生效，未生效时会保留该包，可用下面的 `.bat` 手动完成。
- **便携版一键更新(手动)**: 从 **Release** 页面下载新版便携包后，直接双击同目录下的 `portable_update_by_zip.bat`，根据提示粘贴或拖入 zip 文件（或所在目录），脚本将自动进行双重校验、版本对比（升级自动、降级自动备份）、等待退出并安全覆盖程序文件，**`userdata\` 数据完整保留**。更新为覆盖式（不删除旧版残留程序文件），`userdata\` 与时间戳备份 `userdata.bak_*` 永不被触碰。
- **从安装版迁移**:同一台电脑上首次启动便携版时,会询问是否导入已安装版的数据;导入后原数据保留不动。
- **密码不随迁**:WebDAV / FTP 等网络存储凭据由操作系统加密保管、绑定当前电脑,不包含在 `userdata\` 中;换机后需重新输入一次。
- **安全提醒**:启用元数据设置系统后,网络存储密码将以明文保存在 `userdata\db\` 的数据库文件中。请勿将含密码数据的目录分享给他人;分享前请先删除对应的存储条目或清空其密码。应用内可在 **设置 → 关于 → 数据与密码存储说明** 查看完整说明。
- **高级**:如需强制按安装版模式运行(数据仍存放在系统位置),可设置环境变量 `IRIS_NO_PORTABLE=1`。

| `Shift + >` `,` `/` | 音频同步 +0.5s / −0.5s / 复位                |
| `Ctrl + Home`       | 跳转至中段                                   |
| `Shift + Backspace` | 跳转至结束前 30 秒                           |
| `K` / `Ctrl + E`    | 截存当前帧（PNG，mediaKit 后端）             |
| `Shift + Delete`    | 将播放中文件移入回收站（仅 Windows，可确认） |

前缀序列（先按 `;` 再按一个键）承载 PotPlayer 没有默认键位的旧功能；等待期间会显示
小提示窗，期间按下其他任意合法按键将取消序列并正常执行该按键：

| 序列  | 描述     |
| ----- | -------- |
| `; F` | 存储     |
| `; H` | 播放历史 |
| `; R` | 循环模式 |
| `; X` | 随机     |

A-B 区段循环：`[` 设起点、`]` 设终点（并启动循环）、`\` 开关循环、
`B` 一键布防/重置；循环期间左下角显示指示标记。

硬件媒体键（播放/暂停、上一曲、下一曲）在两种方案下均可用。
对应 PotPlayer 功能尚未实现的按键（`B`、`K`、`H`、`V`、`Tab`、`F11` 等）
暂时留空，待相关能力落地后再绑定。

## 自定义桌面入口

在 **设置 → 通用 → Custom desktop entries** 中，可以为 IRIS 创建自定义图标和名字的桌面入口，并可选择为每个入口绑定独立的播放配置（需开启元数据设置系统）。

### 创建入口

1. 选择一张图片，自由裁剪、缩放
2. 输入自定义名字
3. （可选）绑定一个场景（Scenario）和标签——从该入口进入将按此配置播放
4. 点击「Create & pin」，并在系统确认框中允许添加

| 平台    | 行为                                                             |
| :------ | :--------------------------------------------------------------- |
| Android | 桌面新增快捷方式；原 IRIS 图标保留，可长按自行移除                |
| Windows | 在桌面创建指向 IRIS 的快捷方式；开始菜单/任务栏图标不变           |

### 编辑与删除

- **随时修改**：重新打开编辑器即可换图、改名，保存后桌面入口原地更新
- 删除：Windows 直接删除桌面上的快捷方式文件；Android 因系统限制无法程序化移除已钉住的快捷方式，请长按图标手动删除

### 播放绑定规则

- 每个入口绑定独立的场景 + 标签组合，各入口分别记忆上次播放进度
- 从自定义入口进入：以绑定的场景继续播放；绑定了标签则切入该标签视图
- 从默认图标进入：自动恢复默认的播放状态
- 入口绑定的场景或标签被删除时，会提示重新绑定或退化为普通播放

### 已知限制

- 卸载应用后，桌面快捷方式会被系统自动清除
- 清除应用数据后，旧桌面快捷方式可能失效，可在设置中重建
- 个别第三方桌面（Launcher）不支持添加快捷方式；Android 需 8.0+
